# 璃游 LumaDock 0.2 使用说明

璃游是 Mac 专用游戏启动器，适用于 Apple Silicon、macOS 26 及以上。应用使用本地 ad-hoc 签名，尚未公证。

1. 打开 DMG，将 **LumaDock.app** 拖入“应用程序”。首次打开若被 macOS 拦截，在“系统设置 → 隐私与安全性”中核对来源后选择“仍要打开”。
2. 先完成向导第一步“检查并安装环境”。应用自动检查硬件、系统、完整 Xcode、Metal、应用组件与可用空间。缺少 Xcode 时先获取完整应用，打开一次，完成许可及初始组件安装；可填写实际 Developer 目录再重新检查。缺少 Metal 时点击安装按钮，方式见 [Apple 说明](https://developer.apple.com/documentation/xcode/downloading-and-installing-additional-xcode-components)。其他构建依赖已随应用提供。检查通过后才能继续。
3. 在第二步选择游戏库文件夹。可以选择外置硬盘；运行和准备游戏时保持连接。
4. 在第三步导入玩家自己的 `prod.keys` 文本文件。通常只需导入一次，可供多款游戏共用。格式通过后才能继续，首次读取 NSP 时进一步验证解密能力。密钥不上传，权限为 0600。
5. 在第四步点击“添加游戏”，多选本体、更新和 DLC 的 NSP，或扫描文件夹。支持中文和空格路径。之后也可以从工具栏、菜单或拖入添加；环境或密钥未就绪时，均会引导到对应步骤。首次导入会完整读取并校验文件，可能需要一些时间。
6. 默认开启“导入后自动准备支持的游戏”。导入成功且文件齐全、版本与构建标识匹配时，再次检查工具链并加入准备队列；重复导入不会触发准备。缺少内容会列在游戏详情中，补齐后再准备。若工具链后来不可用，保留导入结果，完成安装后手动点击“准备运行文件”。“准备任务”显示真实阶段、计数或不定进度。成功后由你点击“启动游戏”，不会自动启动。可在向导或设置关闭自动准备，改为手动准备。

应用没有内置任何游戏、更新、DLC、固件、玩家密钥、游戏封面或玩家缓存。封面仅从玩家导入的游戏读取。只有引擎白名单中已适配的指定版本允许构建；其他游戏可以登记但无法构建。兼容性等级以实际 Mac 测试为依据。

## Xcode 与 Metal 组件

“在 App Store 获取 Xcode”直接打开 Mac App Store 中的 Xcode 页面，设置和首次运行向导使用同一入口。设置页不再展示兼容性配置列表，已实测游戏及范围见 README。

“安装 Metal 编译组件”使用 Apple 的 `xcodebuild -downloadComponent MetalToolchain`；已安装时禁用安装按钮。当前 Xcode 支持命令行卸载且检测到 Metal 时，提供“卸载 Metal 编译组件…”，确认后使用 `xcodebuild -deleteComponent MetalToolchain`。这是共享组件，卸载会影响其他依赖该编译器的项目；游戏、密钥与存档保留，再次准备游戏前需要重新安装。

游戏运行、准备队列或组件管理任务进行中时，安装与卸载禁用。操作成功、失败或取消后都会重新检查实际状态。当前 Xcode 不支持卸载接口时，卸载按钮禁用。应用通过 Apple 工具管理组件，不手动删除 Xcode 或组件目录。

## 键鼠和手柄

游戏详情可编辑每游戏配置；设置页可以编辑全局默认。保存后在下次启动生效，不需要重新编译。重复输入会提示冲突并禁止保存。按键录入支持 Shift、Ctrl、Option 以及组合键；Command 留给系统，Esc 留给鼠标捕获。

《旷野之息》默认：WASD 移动，鼠标转视角；E=A，Shift=B，空格=X，左键=Y，右键=ZL；Q=L，G=R，R=ZR；Ctrl=左摇杆按下，C=右摇杆按下；Tab=＋，M=－；方向键=十字键。Esc 切换捕获；没有旧版重复别名。其他游戏显示 Switch 按钮名称。

“鼠标与摇杆”可调整横纵灵敏度、反转、停止回中、摇杆死区与轴映射。触屏模式下左键用于触屏指针，优先于左键按钮绑定。失焦、最小化和系统文字输入框出现时释放捕获并清空输入。需要触屏指针的游戏应选择触屏模式。

手柄通过 macOS GameController 接入，支持一个扩展手柄。默认按物理位置：east=右侧 A，south=下方 B，north=上方 X，west=左侧 Y。支持双摇杆、扳机、肩键及方向键；不含体感和震动。手柄断开后其输入立即清空。“输入测试”可查看实际设备状态。

## 任务、文件和恢复

- 同时只准备一款游戏，准备与游戏运行互斥。准备时可以继续导入和修改设置。
- 取消会停止相关子进程；重试重新验证已完成阶段，未完成阶段重新执行。工具链变化会创建新的缓存。
- 安装时原子切换成功运行目录；失败不会覆盖上一个成功版本。存档和运行时图形管线记录独立保存。首次进入新场景仍可能卡顿。
- 应用重启后保留游戏库和任务。中断任务需要手动重试。
- “移出游戏库”只隐藏条目，保留托管文件和存档；再次导入可恢复登记。“清理缓存”和“删除托管 NSP 副本”分别确认，均不删除玩家原始文件和存档。
- 存档在 `<游戏库>/saves/<Title ID>`；运行目录在 `games/<Title ID>/current`；源文件在 `sources`；构建缓存在 `cache`；运行时管线记录在 `games/<Title ID>/pso_user`。可在游戏详情打开存档位置。
- 现有《旷野之息》玩家可先导入 NSP，再在详情中选择“迁移已有旷野之息构建”，选择原 `BreathOfTheWild` 文件夹。仅接受版本和着色器链一致、资源完整的来源，会重新构建主程序。旧目录和旧存档不受影响。
- 设置中的“导出诊断包”仅导出状态及经过清理的文本日志，不包含密钥、游戏、存档或着色器缓存。

## 当前边界

支持 NSP 文件与文件夹、本体/更新/DLC，接入固定 nxnative 配置。XCI、NSZ、模拟器后端、联网、体感及震动不在首版范围。具体实测结果和硬件限制见随源码的验收记录。实验性游戏可能无法启动或完成游戏；不会根据文件名猜测适配版本。


## 外观与升级

璃游采用系统原生 Liquid Glass，跟随 macOS 明暗外观及“减少透明度”，在 macOS 27 检查；最低支持目标仍为 macOS 26。更名保留旧版 NS Mac 的应用标识、游戏库与映射。不要同时运行新旧版本。图标的 ICO 用于通用分发，Mac 应用使用 ICNS。上游来源、风险和版权说明见 README 及第三方许可。

## 界面语言

应用默认跟随 macOS 语言；首次运行向导和“设置 → 语言”均可切换 English、简体中文或跟随系统，界面立即更新并记住选择。切换无需重新导入游戏、密钥或重新编译。向导、映射、任务进度、已有任务记录和应用错误提示均支持两种语言；游戏内容和原始编译日志保持原样。系统文件对话框的内置按钮跟随 macOS 语言。

## 应用外观

在“设置 → 语言与外观 → 外观”选择“跟随系统、浅色或深色”。选择立即生效，重启后保留；只控制璃游，不修改 macOS 的全局外观。
