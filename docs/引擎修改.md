# 固定引擎与补丁

基线：seedds/nxnative `4e2dcdc749668ddd4d61361117ad4a6980fabcf7`。不自动更新分支。

- `dm/tools/nx_extract/Program.cs`：增加 `--inspect` JSON 接口，解密 CNMT/Control/Code NCA 以识别实际内容、版本、构建标识和封面；增加基于文件系统长度的 `NSMAC_PROGRESS` 提取计数。
- `dm/host/front_mac.m`：保留之前的 Mac 前端修复，使用可配置键盘/鼠标及触屏指针，鼠标捕获与失焦清理，独立游戏线程。
- `dm/host/input_config_mac.h`：`DM_INPUT_CONFIG` v1 读取、唯一绑定检查、组合键、物理手柄按钮、双摇杆和扳机、死区/反转、断开清零。
- `dm/host/mouse_mac.h`：相对鼠标位移转右摇杆，平滑、幅度限制、停止回中；支持运行配置横纵灵敏度/反转。
- `dm/host/Makefile`：跟踪新头文件，链接 GameController。
- `dm/host/tests/Makefile` 和 `t_mouse_mac.c`：鼠标运动数学测试。
- `dm/gfx/tools/dmsh_chain.py`：璃游通过 `DM_MAC_ONLY=1` 仅验证 macOS Metal 工具指纹，Mac 构建不依赖其他平台的 SDK。上游未设置此变量时维持原行为。此修改参与私有工具链及缓存身份计算。

启动器自己的 Mac Worker 位于 `Worker/`，负责直接构建 macOS 运行产物，不内置任何游戏资料。打包时排除上游截图/图片和编译输出，只带源码、配置及必需翻译组件。构建期间所有 profile 工具锁/header 变化位于游戏库的私有引擎副本。
