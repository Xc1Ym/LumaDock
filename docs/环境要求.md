# 运行与构建环境

首次设置与设置页使用同一套检查。每次启动自动检查一次，打开设置复用结果；点击“重新检查”、切换引擎/Xcode/游戏库或组件管理结束后重新验证。环境失败时仍可“稍后设置”/Esc 返回，或“退出璃游”/⌘Q 正常退出。

## 内置 nxnative

应用内置 nxnative 源码、着色器翻译器及已编译的 LibHac 元数据读取器。点击“准备引擎工具”即可校验并复制到私有缓存，安装包用户无需单独下载引擎、安装 .NET SDK 或恢复 NuGet。自行编译 App/DMG 的开发者仍需 .NET 10 SDK。

清单记录上游提交与逐文件哈希。应用优先使用内置引擎，旧的外部目录偏好不再决定运行版本。应用更新后引擎身份变化，需要重新准备游戏才能构建新版宿主；已有成功运行版本继续保留。源码与应用资源保持只读。

Switch Pro A / Xbox A / PS 叉键通过 GameController 自动产生游戏 A。Nintendo 保持标识 A/B/X/Y；Xbox 保持字母；PS 叉/圆/方/三角对应 A/B/X/Y。原生手柄不依赖 `DM_INPUT_CONFIG`，可选映射编辑器仍需引擎提供该独立接口。

仓库每天通过 CI 验证后同步 nxnative；想使用最新同步版本可自行编译 App/DMG，Release 按需提供。

## Xcode 与 Metal

点击“在 App Store 获取 Xcode”，打开 Xcode，由玩家完成许可及首次组件安装。非默认位置通过“选择 Xcode.app…”指定，再重新检查。应用只为自己的进程设置 `DEVELOPER_DIR`，不修改全局 `xcode-select`。

Xcode 就绪后点击“安装 Metal 编译组件”，通过 Apple 的 `xcodebuild -downloadComponent MetalToolchain` 安装。支持时可确认卸载共享组件。参考 [Apple 官方说明](https://developer.apple.com/documentation/xcode/downloading-and-installing-additional-xcode-components)。这些操作不下载引擎。

初始设置仍失败时，展开“安装与修复方法”，查看实际路径、状态命令与错误。若 Xcode 已设置完成，先重新检查或退出重开璃游。可复制的手动修复命令会安装初始组件并接受许可；执行前自行阅读并同意 Xcode 许可。璃游不会自动执行管理员命令。

## 内置依赖与离线说明

通用运行环境相对应用当前位置解析，位于 `Contents/Resources/Runtime`。.NET 打印的完整路径是当前实际位置，不是开发者路径。移动或重命名整个应用不需要重装 Python/.NET，打包会审计本机二进制依赖路径。

玩家不需要系统 Python 或 Homebrew。内置组件损坏时请重新安装完整璃游，不要用 pip 修改包内 Python。引擎故障通过重新安装完整应用、重新准备私有工具缓存修复。

“环境安装说明”直接打开本机内置阅读器，无需 Markdown 编辑器。已有完整运行产物且启动检查通过时，即使引擎工具暂时不可用，也可启动已准备好的游戏；导入、更新或重新准备时仍需修复内置引擎与工具。
