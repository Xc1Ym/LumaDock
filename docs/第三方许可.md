转换命令调度、机器可读与 tqdm 进度解析参考 [SAK-Mac](https://github.com/ggaoph-lab/SAK-Mac) 的 `c8e0baa59a168d9efaa0b556af70e0a08bda51de`，Copyright (c) 2026 ggaoph-lab。完整上游 [MIT 许可](licenses/SAK-Mac-LICENSE.txt) 保留在源码及应用文档中。

[NSC_BUILDER](https://github.com/julesontheroad/NSC_BUILDER)（`e9083e83383281bdd9e167d3141163dcc56b6710`，MIT）与 [nsz](https://github.com/nicoboss/nsz)（`4aea60e8ea7cb1099f286fc57cc7aade6338f32c`，MIT）内置于 `Runtime/converter`。NSC_BUILDER 应用 SAK-Mac 的 Python 3.11+ / macOS 补丁；上游完整许可和补丁保留在 `Runtime/converter/licenses`。密钥不随应用提供，NSC_BUILDER 使用私有临时副本执行。
